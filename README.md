# Codex Island

面向 MacBook 的原生 Codex 灵动岛，独立第三方项目。使用 AppKit + SwiftUI，支持 macOS 14 及以上，构建包含 Apple Silicon 与 Intel 架构。

## 使用

启动 `Codex Island.app`。默认在 MacBook 刘海居中位置显示灵动岛，顶部高度跟随当前菜单栏，宠物和任务状态分别位于刘海两侧。悬停展开任务，点击可固定预览，再点收起；点击外部或按 Escape 收起。`Control + Option + I` 展开或收起；右侧小菜单栏图标保留新对话、设置和退出等辅助入口。

- 任务标题右侧显示来源：本机、远程机器名称、Codex 云端或 ChatGPT / Work 云端。长名称可悬停查看全文。
- 本机与远程任务点击后由 Codex 打开原对话；Codex Cloud 与 ChatGPT 对话打开对应网页。同一任务 ID 同时出现在多台机器时，提示在 Codex 中选择机器，避免打开错误副本。
- 额度刷新入口依次显示持续旋转的白色双箭头、成功打勾和刷新图标；成功反馈停留约 1.4 秒。失败显示独立提示，不显示成功勾；尊重系统减少动态效果设置。
- 设置内的“显示额度”开关默认开启并持久保存；关闭后隐藏百分比和刷新入口、停止发起额度读取，重新开启时读取。
- “当前动态”右侧显示当前账户的剩余额度百分比，旁边可点击刷新。应用启动时读取一次，动态面板展开时每 60 秒自动读取；重新展开会按 30 秒最短间隔补读。收起时暂停周期读取，不显示更新时间。读取失败或数据过期时显示“—”，悬停可查看提示。
- 收起状态的提示点在有运行、待处理或新内容时显示黄色；就绪为绿色，未连接为灰色。
- 顶部 ×数量合并统计进行中、待处理和新内容任务，同一任务只计一次。默认优先展示待确认/待处理、正在运行和有未读新内容的任务；普通最近任务折叠，需要时点击“查看最近任务”。同类按最新活动排序，有新内容时显示“新”标记；阅读状态由 Codex 同步。
- 新对话支持在岛内输入，再交给 Codex 原生对话页继续。
- 宠物在灵动岛中常驻显示，独立于 Codex 自身的宠物显示开关；设置保留宠物选择、悬浮胶囊、屏幕选择、登录启动和 Codex 原生设置入口。
- 默认优先内置刘海屏，合盖或无内置屏时回退至可用屏幕，手动选择显示屏时尊重设置。刘海区域保留空白，展开内容位于安全区及菜单栏下方；无刘海屏和可选悬浮模式使用可见区域内的胶囊。
- 设置中的文件夹按钮可导入自定义 `pet.json`。支持本机 Codex 内置宠物，以及 v1/v2 的本地精灵图。云端独占、尚未落地为本地资源的宠物不自动下载。
- 辅助菜单中的“恢复默认位置”可恢复刘海居中模式。

## 从源码构建

本仓库为完整 Swift Package，不需要下载第三方 Swift 依赖，也不需要安装可选的 Codex 插件。应用当前版本为 0.1.23。

准备一台 Mac、支持 Swift 5.10 或以上及 macOS 14 SDK 的 Xcode / Command Line Tools。构建和测试不依赖 Codex 登录；实际显示任务、额度和宠物需要安装兼容的 Codex 桌面客户端并登录自己的账户。

解压源码后，在包含 `Package.swift` 的目录打开终端：

```sh
swift --version
swift build
swift test
```

上述命令检查源码并运行测试，不要求提供签名证书。生成可双击的应用还需要使用构建者自己的 Apple Development 或 Developer ID Application 签名身份：

```sh
security find-identity -v -p codesigning
bash scripts/build-app.sh
```

产物为 `dist/Codex Island.app`，包含 arm64 与 x86_64。把它拖到“应用程序”目录，然后打开即可；不要把编译得到的裸二进制当作安装包。

如果没有证书，可在 Xcode 的账户与证书管理界面配置自己的 Apple Development 身份后重试。仓库不包含作者的证书或私钥；脚本不会静默改用 ad-hoc 签名。也可显式选择已有身份，并将产物写到指定的绝对目录：

```sh
CODEX_ISLAND_SIGN_IDENTITY="你的签名身份名称或哈希" bash scripts/build-app.sh "/绝对路径/发布目录"
```

Apple Development 签名适用于开发测试，不能等同于已公证的公开分发包。向其他设备提供二进制前，应另行完成 Developer ID 分发签名、公证和干净设备测试；本脚本只负责构建与签名，不自动公证。

构建与运行验证的具体范围、历史打包记录及当前限制见 [VALIDATION.md](VALIDATION.md)。

如果使用 GitHub 网页上传，请先解压，再将本目录中的文件和文件夹上传到仓库根目录，让 `README.md` 和 `Package.swift` 直接位于根目录；也一并保留 `.gitignore` 和插件中的 `.codex-plugin/` 隐藏目录。ZIP 本身可作为 Release 附件，单独上传 ZIP 不会展开成可浏览的源代码。

## 诊断

```sh
"dist/Codex Island.app/Contents/MacOS/CodexIsland" --diagnose
```

`--diagnose` 只读连接约 4 秒，输出连接与素材统计，不输出聊天内容。

`--diagnose-sources` 还会查询云端目录和机器名称，最长等待约 26 秒，输出各来源数量及机器名称；不输出任务标题或认证信息。

## 兼容边界

当前适配 Codex Desktop `26.901.51231` 的本机 IPC 快照协议 v11。该协议属于客户端内部接口，Codex 更新可能需要适配。应用遇到不兼容会撤销实时状态并显示连接提示，不修改安装包，不更改 Codex 配置，不创建额外的 agent 执行进程。

各来源合并到同一个列表，仍按待处理、运行中、新内容和最近任务排序：

| 来源 | 目录与名称 | 状态范围 |
| --- | --- | --- |
| 本机 | 只读 SQLite，最近 24 条 | IPC v11 快照与增量 |
| 远程控制、SSH 等远程主机 | 客户端已同步的 `remote-thread-summaries-v3` 缓存，每台最近 24 条；远程控制读取客户端显示名，SSH 使用保存的连接名称 | 按主机 ID 独立订阅 IPC；未收到快照显示“状态未同步”，已知离线显示“主机离线” |
| Codex Cloud | 云端当前任务列表，最近 20 条；显示“Codex 云端”及环境名 | 每 30 秒只读查询排队、运行、完成、失败及未读标记；查询失败或超过 90 秒撤销旧状态 |
| ChatGPT / Work 云端 | 当前登录账户的客户端缓存，最多 24 条 | 显示“缓存记录 · 无实时状态”，不推断运行、完成或未读 |

额外保留最多 12 条已观察到的活跃、待处理或未读 IPC 任务。缓存中没有的远程历史任务不会自动扫描远端文件系统。没有实时状态或未读证据的记录归入折叠的“最近任务”。机器名称无法读取时显示远程标识，设置页说明来源可用性。

IPC 连接成功不代表客户端一定提供任务快照。当前客户端运行方式可能不对外发布普通任务的快照；此时本机与远程仍可显示目录，实时状态保持不可用。ChatGPT 对话接口在本次环境返回拒绝访问，因此这类对话只使用账户隔离的缓存，没有绕过权限。

机器名称与 Codex Cloud 查询复用 Codex 已有 ChatGPT 登录，通过短暂的 App Server 元数据辅助进程取得临时认证信息；仅向固定的官方 HTTPS 目录接口发送 GET，关闭重定向、Cookie 和磁盘缓存，完成后丢弃认证信息。不会主动刷新认证、配对设备、修改 Codex 设置或执行云端任务。账户切换时清空上一账户的云端记录。

额度通过公开的 `account/rateLimits/read` 读取，优先使用 Codex 额度桶的主周期，主周期不可用时回退到可用的次周期；显示 `100 - usedPercent` 向下取整后的百分比。悬停可查看实际周期及剩余额度，不把每周额度误标为 5 小时额度。读取使用短暂启动的本机 App Server 辅助进程，完成后关闭；不创建对话、不执行任务、不购买或使用重置。

快捷输入由 Codex 深链接接收；授权决定、长对话和语音继续使用 Codex 原生界面。应用不提供直接执行授权的按钮。
